# AI Smart Mushroom Farm

ระบบควบคุมสภาพแวดล้อมโรงเพาะเห็ดอัจฉริยะด้วยปัญญาประดิษฐ์
และตรวจวัดการเจริญเติบโตของเห็ดด้วย Computer Vision

**ทีม โจรสลัดพิกเซล** · UP AI Hackathon 2026 · มหาวิทยาลัยพะเยา
1. ปิยนันท์ ทรงศรี
2. สุดา ใจแก้ว

---

## เป้าหมายของโครงงาน

เห็ดต้องการอุณหภูมิ 22–28 °C และความชื้น 78–90 %RH การเบี่ยงเบนเพียงไม่นานทำให้ผลผลิตลด
เกิดเชื้อรา เห็ดแคระ หรือเน่าเสีย ระบบนี้จึงทำหน้าที่

1. อ่านและจัดเก็บอุณหภูมิ-ความชื้นทุก 10 วินาที พร้อมตรวจสอบความถูกต้องของค่า
2. แสดงผลบน Dashboard เรียลไทม์ที่เปิดได้จากมือถือ
3. ควบคุมพัดลม เครื่องเพิ่มความชื้น และระบบระบายอากาศอัตโนมัติ พร้อมสถานะปลอดภัยเมื่อระบบล้มเหลว
4. ใช้ AI พยากรณ์อุณหภูมิล่วงหน้า 1 และ 6 ชั่วโมง และแนะนำการปรับพร้อมค่าความเชื่อมั่น
5. ใช้ Computer Vision วัดขนาด จำนวน ระยะการเจริญเติบโต ความพร้อมเก็บเกี่ยว และความผิดปกติของเห็ด

**หลักการสำคัญ:** การควบคุมทางกายภาพต้องไม่พึ่งพา AI หรือเครือข่ายเพียงอย่างเดียว
ชั้นควบคุมแบบ rule-based ทำงานได้เองเสมอ และมี Safe-State ต่ออุปกรณ์

## โครงสร้างที่เก็บ

```
app/            แอปพลิเคชัน (โหมดจำลอง) — ดูรายละเอียดใน app/README.md
  src/          core.js (เอนจิน) · ui.js · styles.css · body.html
  test/         ชุดทดสอบตรรกะควบคุมและความปลอดภัย 22 ข้อ
  build.mjs     รวมเป็น HTML ไฟล์เดียว
docs/index.html แอปเวอร์ชันไฟล์เดียว (ใช้เผยแพร่ผ่าน GitHub Pages ได้ทันที)
presentation/   โปสเตอร์ A0 และสไลด์นำเสนอ
SPEC.md         ข้อกำหนดต้นฉบับที่ผ่านการตรวจความกำกวม/กรณีขอบ/ความปลอดภัย
.planning/      เอกสารวางแผน: PROJECT · REQUIREMENTS (31 ข้อ) · ROADMAP (5 เฟส) · STATE
```

## เปิดใช้แอป

```bash

# แก้ไขซอร์สแล้วสร้างใหม่
cd app && node build.mjs

# รันชุดทดสอบ
cd app && node test/core.test.mjs      # ต้องผ่าน 22/22
```

## สถานะการพัฒนา

| เฟส | เนื้อหา | สถานะ |
|---|---|---|
| 1 | รับข้อมูลเซนเซอร์และความปลอดภัยอุปกรณ์ | ตรรกะพร้อม (ใช้ตัวจำลอง) |
| 2 | Dashboard เรียลไทม์และกราฟย้อนหลัง | เสร็จ |
| 3 | ควบคุม rule-based, แจ้งเตือน, Safe-State | เสร็จ |
| 4 | AI พยากรณ์และคำแนะนำแบบมีค่าความเชื่อมั่น | เสร็จ (MAE 1 ชม. ≈ 0.6 °C) |
| 5 | Computer Vision ตรวจวัดการเจริญเติบโต | จำลองครบทุกตัวชี้วัด รอชุดข้อมูลภาพจริง |

ยังไม่ได้ต่อกับเซนเซอร์จริง — เมื่อมีอุปกรณ์ ให้แทน `readSensor` และ `physics`
ใน `app/src/core.js` ด้วยข้อมูลจาก ESP32 + SHT31-D (รายละเอียดท้าย `app/README.md`)
