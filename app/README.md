# AI Smart Mushroom Farm — แอปพลิเคชันโหมดจำลอง

ทีม **โจรสลัดพิกเซล** · UP AI Hackathon 2026
1. ปิยนันท์ ทรงศรี  2. สุดา ใจแก้ว

แอปควบคุมสภาพแวดล้อมโรงเพาะเห็ดอัจฉริยะ ทำงานได้จริงทั้งหมดโดยใช้ **แบบจำลองโรงเรือน**
แทนเซนเซอร์จริง — ตรรกะการควบคุม ระบบความปลอดภัย และส่วน AI เป็นชุดเดียวกับที่จะใช้
เมื่อต่อกับ ESP32 + SHT31-D จริงในภายหลัง

## วิธีเปิดใช้

| วิธี | ขั้นตอน |
|---|---|
| **ติดตั้งลงมือถือ** | เปิด https://67100251bank.github.io/ai_smart_farm/ แล้วสั่งติดตั้ง (ดูข้างล่าง) — ได้ไอคอนบนหน้าจอโฮม เปิดเต็มจอ ใช้ได้แม้ไม่มีเน็ต |
| **เปิดผ่านเบราว์เซอร์** | เปิดลิงก์เดียวกันได้เลย ไม่ต้องติดตั้ง |
| **คอมพิวเตอร์ / ออฟไลน์ล้วน** | ดับเบิลคลิกไฟล์ `smart-farm-app.html` — ไฟล์เดียวจบ ไม่ต้องมีเซิร์ฟเวอร์และไม่ต้องมีอินเทอร์เน็ต |

แอปเก็บสถานะไว้ในเบราว์เซอร์ (localStorage) ปิดแล้วเปิดใหม่การจำลองจะเดินต่อจากเดิม

### ติดตั้งลงมือถือ (PWA)

**Android (Chrome)** — เปิดลิงก์ → เมนู ⋮ → *ติดตั้งแอป* / *เพิ่มไปยังหน้าจอหลัก*
หรือเปิดในแอปแล้วกดไอคอนเฟือง → ปุ่ม **ติดตั้งแอป**

**iPhone / iPad (Safari)** — เปิดลิงก์ → ปุ่ม **แชร์** → *เพิ่มไปยังหน้าจอโฮม* → *เพิ่ม*

หลังติดตั้ง แอปจะเปิดแบบเต็มจอไม่มีแถบเบราว์เซอร์ และเปิดได้แม้ปิดอินเทอร์เน็ต
(service worker เก็บไฟล์แอปไว้ในเครื่องหลังเปิดครั้งแรก)

## หน้าจอ

| แท็บ | เนื้อหา |
|---|---|
| **ตรวจวัด** | อุณหภูมิ/ความชื้นปัจจุบัน สถานะการเชื่อมต่อ สรุปการทำงาน และแจ้งเตือนล่าสุด |
| **แนวโน้ม** | กราฟย้อนหลัง 30 นาที–48 ชม. + เส้นพยากรณ์และช่วงความเชื่อมั่น + ตารางข้อมูล |
| **ควบคุม** | สั่งงานอุปกรณ์ด้วยมือ ตั้งช่วงเป้าหมายต่อโซน ดูการตัดสินคำสั่งขัดแย้ง และประวัติคำสั่ง |
| **AI** | สถานะบริการ AI, ค่าพยากรณ์ 1/6 ชม., MAE ที่วัดได้จริง, รูปแบบที่ตรวจพบ, คำแนะนำพร้อมค่าความเชื่อมั่น |
| **เห็ด** | ภาพจากกล้อง (จำลอง) พร้อมกรอบตรวจจับ ตัวชี้วัดการเจริญเติบโต ความผิดปกติ และกราฟการโต |
| **ตั้งค่า** (ไอคอนเฟือง) | บทบาทผู้ใช้ ธีมสี เกณฑ์แจ้งเตือน และ **สถานการณ์ทดสอบระบบความปลอดภัย** |

## สถานการณ์ทดสอบ (ใช้ตอนนำเสนอ)

เปิดจากไอคอนเฟืองมุมขวาบน แล้วเร่งความเร็วเป็น ×60

| สถานการณ์ | สิ่งที่จะเห็น |
|---|---|
| อากาศร้อนจัด | อุณหภูมิพุ่ง → พัดลม+ระบายอากาศทำงาน → แจ้งเตือนวิกฤต → AI แนะนำการปรับ |
| เซนเซอร์ขาดการเชื่อมต่อ | สถานะ online → stale → offline, ค้างคำสั่ง 5 นาที แล้วเข้า **Safe-State** ต้องกดรับทราบ |
| อุปกรณ์ไม่ตอบรับคำสั่ง | ลองซ้ำ 3 ครั้ง → เข้าสถานะปลอดภัยต่ออุปกรณ์ (พัดลม/ความชื้น ปิด, ระบายอากาศ เปิด) |
| บริการ AI ล่ม | สลับไปตัวควบคุมตามกฎทันที การควบคุมไม่มีช่องว่าง |
| กล้องส่งภาพไม่ได้คุณภาพ | ข้ามรอบวิเคราะห์ + แจ้งเตือน |
| บทบาท "ผู้ชม" | ปุ่มสั่งงานอุปกรณ์ถูกปิดทั้งหมด |

## ความสอดคล้องกับ SPEC

ตรรกะทั้งหมดอิงข้อกำหนดใน `.planning/REQUIREMENTS.md`

- **SENS-01/02/03** อ่านค่าทุก 10 วินาที · ตรวจช่วงที่เป็นไปได้และอัตราการเปลี่ยนแปลง (ติดธงไม่ทิ้งข้อมูล) · เก็บข้อมูลดิบ + ค่าเฉลี่ยราย 5 นาที
- **DASH-01/02/03** ค่าปัจจุบันอัปเดตต่อเนื่อง · สถานะ online/stale/offline · กราฟย้อนหลัง
- **CTRL-01…06** ยืนยันคำสั่งภายใน 5 วินาที ลองซ้ำ 3 ครั้ง · คำสั่งด้วยมือมีสิทธิ์เหนือระบบ 15 นาที · จำกัด 1 คำสั่ง/30 วินาที · ตัดสินคำสั่งขัดแย้งด้วยค่าเบี่ยงเบน · ตั้งเป้าหมายต่อโซนพร้อมตรวจค่า 50–95 %RH
- **ALRT-01/02** แจ้งเตือน push+email เมื่อเกินเกณฑ์ · รวบซ้ำภายใน 15 นาที
- **FAIL-01…04** สลับไปตัวควบคุมตามกฎเมื่อ AI ล่ม · ค้างคำสั่งเมื่อข้อมูลค้าง แล้วเข้า Safe-State · อุปกรณ์ไม่ตอบสนองต้องให้คนรับทราบ · ข้ามรอบเมื่อภาพไม่ได้คุณภาพ
- **AIAN-01…05** ตรวจจับแนวโน้ม/การแกว่ง/ความผิดปกติรายวัน · พยากรณ์ 1 และ 6 ชม. พร้อมช่วงความเชื่อมั่น · คำแนะนำแบบมีค่าความเชื่อมั่น · **ต่ำกว่า 0.6 ไม่สั่งงานอัตโนมัติทุกกรณี** · โหมดอัตโนมัติเป็น opt-in
- **CV-01…05** ถ่ายภาพทุก 30 นาที · วัดจำนวน/ขนาด/พื้นที่ปกคลุม/สี/ระยะ · ความพร้อมเก็บเกี่ยวจากระยะ+ขนาด · ความผิดปกติ 4 ประเภท (แจ้งเตือนเท่านั้น ไม่สั่งแก้ไขเอง)
- **SEC-02/03** สั่งงานได้เฉพาะ operator/admin · ตรวจลายเซ็นแพ็กเก็ตและปฏิเสธข้อมูลปลอม

ค่าพยากรณ์คำนวณด้วยแบบจำลองสถิติ (Holt แบบแนวโน้มหน่วง + ส่วนประกอบวัฏจักรรายวัน)
ไม่ได้ให้ภาษาโมเดลคำนวณตัวเลขคำสั่ง ตามข้อกำหนด AIAN-04

## โครงสร้างซอร์ส

```
src/core.js        เอนจินทั้งหมด: แบบจำลอง, ตรวจสอบค่า, สั่งงานอุปกรณ์, Safe-State, แจ้งเตือน, AI, CV
                   (ไม่พึ่ง DOM — ทดสอบด้วย Node ได้ตรง ๆ)
src/ui.js          ส่วนติดต่อผู้ใช้ กราฟ canvas และภาพจำลองจากกล้อง
src/styles.css     ระบบสีและเลย์เอาต์ (รองรับธีมสว่าง/มืด)
src/body.html      โครงหน้า
src/pwa/           ไฟล์สำหรับติดตั้งลงมือถือ: manifest, service worker, ไอคอน (SVG ต้นฉบับ + PNG)
build.mjs          สร้าง 3 ผลลัพธ์: artifact-body.html, smart-farm-app.html (ไฟล์เดียว), pwa/ (สำหรับ GitHub Pages)
test/core.test.mjs ชุดทดสอบตรรกะควบคุมและความปลอดภัย 22 ข้อ
```

### คำสั่ง

```bash
node build.mjs            # สร้างไฟล์ผลลัพธ์ใหม่ทั้งหมดใน dist/
node test/core.test.mjs   # รันชุดทดสอบ (ต้องผ่าน 22/22)

# นำขึ้นเว็บ: คัดลอกทุกอย่างใน dist/pwa/ ไปทับโฟลเดอร์ docs/ ของที่เก็บนี้
cp -r dist/pwa/* ../docs/
```

> ถ้าแก้ไฟล์แอปแล้วนำขึ้นเว็บใหม่ ให้แก้เลขเวอร์ชันใน `src/pwa/sw.js`
> (ตัวแปร `VERSION`) ด้วย เพื่อให้เครื่องที่ติดตั้งไว้แล้วดึงเวอร์ชันใหม่

## ก้าวต่อไปเมื่อมีอุปกรณ์จริง

1. เขียน firmware ESP32 ส่ง `{deviceId, ts, nonce, temp, humid, sig}` ผ่าน HTTPS
2. ทำ Express API รับข้อมูลและตรวจลายเซ็น แล้วเรียกฟังก์ชันเดิมใน `core.js` แทนตัวจำลอง
   (`readSensor` และ `physics` เป็นจุดเดียวที่ต้องเปลี่ยน)
3. ต่อรีเลย์ควบคุมอุปกรณ์เข้ากับ `sendCommand` และส่ง ack กลับจริง
4. เก็บภาพจริงส่งเข้าโมเดล YOLOv8 แทน `cvCycle`
